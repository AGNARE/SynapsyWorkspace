# Плагин: сборка компонентов Synapse

Один раз запускается в Figma и сам собирает библиотеку компонентов с вариантами —
кнопки, поля, бейджи, карточки, строки списка. Ничего нажимать руками не надо.

## Как установить

Нужен **Figma Desktop** — в браузере плагины разработчика тоже работают, но с приложением надёжнее.

1. Скачай папку `synapse-figma-plugin` на компьютер и **распакуй**, если скачал архивом.
   Важно: файлы `manifest.json` и `code.js` должны лежать рядом, в одной папке.
2. Открой Figma и **любой файл** — не обязательно наш.
3. В верхнем меню: **Plugins → Development → Import plugin from manifest…**
4. Выбери файл **`manifest.json`** из папки.
5. Плагин появится в списке: **Plugins → Development → Synapse — сборка компонентов**. Запусти.

## Что произойдёт

Появится новая страница **«Компоненты»**. На ней — наборы вариантов:

| Набор | Вариантов | Что внутри |
|---|---|---|
| `Button` | 16 | вид × состояние: основная, вторичная, иконка, опасная; обычное, наведение, фокус, отключённая |
| `Input` | 8 | поле и выпадающий список в состояниях: обычное, фокус, ошибка, отключённое |
| `Badge / Status` | 6 | шесть статусов задачи |
| `Badge / Priority` | 3 | три приоритета |
| `Chip` | 2 | обычный и активный |
| `Checkbox` | 2 | снят и отмечен |
| `Toggle` | 2 | выключен и включён |
| `Avatar` | 4 | четыре размера: 16, 24, 32, 40 |
| `Card` | 2 | обычная и метрика |
| `Row / Task` | 3 | строка задачи: обычная, наведение, выбранная |

Плюс коллекция переменных **«Synapse»** — 21 цветовой токен из дизайн-системы.

**Итого: 48 компонентов.** Каждый — настоящий компонент Figma, а не картинка:
у него есть имя, свойства вариантов и переменные цвета.

## Как этим пользоваться

- **Поменять цвет везде:** открой компонент `Button`, вариант `Kind=Primary, State=Default`,
  поменяй заливку. Остальные варианты надо будет поправить отдельно — они независимы.
- **Вставить в макет:** панель **Assets** слева, раздел с именем файла. Или скопируй
  компонент с листа и вставь в макет.
- **Добавить вариант:** выдели набор, справа в панели **Variant** добавь значение свойства.

## Если запустить второй раз

Компоненты продублируются. Это не страшно: удали страницу «Компоненты» и запусти заново —
переменные цвета переиспользуются, дубликатов не будет.

## Что можно дописать

Плагин расширяется: модальные окна, дерево базы знаний, диаграмма Ганта. Логика та же —
добавляется несколько строк в `code.js`. Скажи, что нужно, и допишу.
