# Состояния интерфейса Synapse Workspace — набор для Figma

Пять листов с состояниями, которых не хватало: пустые экраны, загрузка, ошибки,
пространство без модулей и доступность по ролям.

## Что в папке

| Файл | Что внутри |
|---|---|
| `s01-empty-states.svg` | пять пустых состояний: задачи, база знаний, файлы, участники, ассистент |
| `s02-loading-states.svg` | скелетоны метрик, таблицы задач, дерева знаний и ответа ассистента |
| `s03-error-states.svg` | ошибка загрузки, недоступный ассистент, нет прав, ошибка сохранения |

| `s05-roles.svg` | экран «Задачи» глазами владельца, редактора и читателя |
| [_preview/](_preview) | PNG-превью каждого листа |

## Как перенести в Figma

Так же, как модальные окна: установи **Inter**, перетащи `.svg` на холст.
Каждый лист займёт кадр 1440×1024. Листы `s01`, `s02`, `s03`, `s05` — служебные,
их не показывают пользователю, они нужны для сборки состояний в компоненты.
`s04` — настоящий экран.

## Правила, по которым собраны состояния

- **Пустое состояние объясняет, что появится и как это получить**, а не констатирует
  пустоту. Никаких «Данных нет» без действия.
- **Ошибка объясняет причину и даёт действие.** Есть кнопка «Повторить» или
  альтернативный путь; тупика без выхода не бывает.
- **Запрещённое действие объясняет, почему запрещено.** Отключённая кнопка всегда
  стоит рядом с пояснением роли или условия.
- **Скелетон повторяет сетку будущего содержимого**, чтобы экран не прыгал после
  подгрузки. Мерцание не используем.
- **Статус не кодируется только цветом** — рядом всегда текст.
