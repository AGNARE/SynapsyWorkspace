# Правила UI — дизайн-контракт Synapse Workspace

Единый источник правил. Каждая страница ссылается на этот файл.
Если экран требует отклонения — отклонение описывается в `<desc>` самого SVG.

## 1. Формат файла

- Один экран = один самодостаточный SVG. Холст строго `1440 × 1024`, `viewBox="0 0 1440 1024"`.
- Имя файла: `NN-имя.svg` (`01-overview.svg`, `04-task-detail.svg`).
- Файл открывается в Figma и остаётся редактируемым: текст живой, слои именованные.
- Модальные окна — отдельные файлы, холст тот же, содержимое — `backdrop` + `dialog`.

## 2. Технические запреты

Запрещено: `<style>` и CSS-классы, `<image>`, растры base64, `<filter>`, `<mask>`,
внешние ссылки, `data:`-URI, `<foreignObject>`, скрипты, `transform`.
Все свойства — явными атрибутами: `fill`, `stroke`, `stroke-width`, `rx`,
`font-size`, `font-weight`, `text-anchor`.

Текст — только `<text>` и `<tspan>` с координатами `x`/`y`. Никаких кривых вместо букв.
Идентификаторы — латиница, kebab-case, осмысленные: `sidebar`, `nav-overview`,
`kpi-row`, `card-my-work`, `btn-create`.

## 9. Язык и тексты

- Интерфейс — **русский**. Латиница только в названиях технологий:
  Git, Gantt, OCR, API, AI, PDF, DOCX, XLSX, PPTX, PNG, JPEG, RAG, WebSocket, HMAC, JWT.
- `workspace` пишем по-русски — **рабочее пространство** (кроме названий модулей).
- Действия — инфинитив: «Создать задачу», «Загрузить», «Пригласить».
- Даты: «12 октября 2026», «сегодня», «завтра», «2 дня назад». В таблицах — «12 окт».
- Пустое состояние объясняет, что появится и как это получить, без обвинения пользователя.
- Ошибка объясняет причину и даёт действие.

## 10. Доступность

- Минимальный кегль 11 px, основной текст 13 px.
- Контраст текста к фону ≥ 4,5:1; белый текст — только на `#4F46E5` и темнее.
- Статус не кодируется только цветом: рядом всегда есть текст.
- Кликабельная область любого действия ≥ 32×32.
- Фокус — рамка 2 px `#6366F1` вокруг контрола.

## 11. Чек-лист самопроверки

1. Корень ровно 1440×1024, есть `viewBox`, `<title>`, `<desc>`.
2. Группы `sidebar`, `topbar`, `content` в этом порядке.
3. Нет `<style>`, `<image>`, `transform`, `filter`, `mask`, классов, эмодзи.
4. Весь текст — `<text>`/`<tspan>` с `x`/`y`.
5. Все цвета — только из раздела 4.
6. Кегль не меньше 11 px, контраст соблюдён.
7. Нет английских слов сверх списка раздела 9.
8. Идентификаторы уникальны и осмысленны.
9. Размер файла ≤ 30 КБ.
10. Файл парсится как XML без ошибок.
