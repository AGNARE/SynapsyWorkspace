# Synapse Workspace — бренд

Знак, логотип, фирменные цвета и правила использования.

![Брендборд Synapse Workspace](<brandboard.png>)

*Знак, логотип, иконка приложения в шести размерах, фирменные цвета, варианты
размещения и примеры использования.*

## 1. Название

**Synapse** — синапс: место соединения нейронов, через которое проходит сигнал.
Название описывает суть продукта, а не отрасль: платформа так же соединяет
разрозненное — задачи, коммиты из Git, файлы и статьи — в одну связанную систему
с помощью векторного поиска и графа связей.

Полное название продукта — **Synapse Workspace**.

Историческое имя KSTU Workspace выведено из употребления и в новых материалах
не используется.

## 2. Знак

- **Форма** — шестиугольник с буквой S, собранный из двух лент.
- **Идея** — ленты сходятся в центре. Это визуальная метафора синапса: две стороны,
  соединённые в одной точке.
- **Читаемость** — знак работает как самостоятельная иконка, без подписи: грани
  достаточно крупные, чтобы форма читалась в 16 px.
- **Градиент знака** — `#713BFF → #4E69FF → #00D7E8`.
- **Градиент нижней ленты** — `#00CFE8 → #356EFF → #7A35FF`.

## 3. Что означает

| Элемент | Значение |
|---|---|
| Буква S | Synapse — название продукта |
| Сходящиеся ленты | Связь и синхронизация |
| Модульные грани | Модульная архитектура: функции подключаются по необходимости |
| Градиент | Технологичность, развитие, современный подход |

## 4. Логотип

Две компоновки: полная и сокращённая.

- **Полная** — знак слева, справа подпись в две строки: `Synapse` основным цветом,
  `Workspace` — более светлым. Применяется на обложках, сайте, презентациях.
- **Сокращённая** — только знак. Применяется как иконка приложения, favicon
  и в местах, где название уже прозвучало.

В интерфейсе используется своя версия лого-лока: знак 26×31 и две строки текста
прописными — `SYNAPSE` основным цветом, `Workspace` брендовым. Образец — в файле
`sidebar-logo.png`.

## 5. Иконка приложения

Три варианта оформления:

| Вариант | Когда применяется |
|---|---|
| **Dark** | Основной. Тёмная подложка, знак в градиенте |
| **Light** | Светлые поверхности, документы, печать |
| **Gradient** | Промо-материалы, обложки, соцсети |

Размеры:

| Размер | Где используется |
|---|---|
| 1024×1024 | основной, мобильное приложение, магазины приложений |
| 512×512 | сайт |
| 256×256 | веб-приложение |
| 128×128 | меню, списки |
| 64×64 | favicon, документация |
| 48×48 | вкладка браузера |
| 32×32 | интерфейсные иконки |
| 16×16 | микроразмер, системные списки |

## 6. Фирменные цвета

| Цвет | Значение | Роль |
|---|---|---|
| `#6366F1` | индиго | основной бренд-акцент |
| `#8B5CF6` | фиолетовый | второй цвет градиента |
| `#06B6D4` | циан | акцент, свечение |
| `#0F172A` | тёмный | подложки, основной текст на светлом |
| `#E2E8F0` | светлый | границы, разделители |

Интерфейсные токены — отдельная палитра для экранов; она собрана на листе
дизайн-системы.

## 7. Типографика

Основной шрифт — **Inter**. В подписи логотипа используется насыщенное начертание,
в интерфейсе — от 500 до 700 в зависимости от уровня текста.

## 8. Размещение

**Знак на тёмном фоне.** Тёмная подложка `#0F172A` с фирменными дугами. Основной
вариант для обложек и промо-материалов.

**Знак на светлом фоне.** Белая или светлая подложка, знак в градиенте, подпись
тёмным цветом. Используется в документации и интерфейсе.

**Охранное поле.** Вокруг знака оставляется свободное пространство не меньше
половины его ширины. В это пространство не заходят текст, линии и другие элементы.

**Минимальный размер.** Знак — 16 px, полный логотип с подписью — 96 px по ширине.

## 9. Слоган

Основной: **«Единое пространство для идей, команд и знаний»**.

Подпись под логотипом в материалах: **«Synapse Workspace — ваше цифровое пространство»**.

## 10. Примеры использования

| Носитель | Вариант |
|---|---|
| Веб-сайт | иконка 32×32, знак с подписью в шапке |
| Мобильное приложение | иконка 1024×1024, тёмный вариант |
| Favicon | иконка 16×16 или 64×64 |
| Документация | знак с подписью, светлый вариант |

## 11. Файлы бренда

| Файл | Что это |
|---|---|
| `logo-mark.svg` | знак отдельным вектором — вставляется в сайдбар экранов |
| `synapse-brandboard.svg` | полный брендборд: знак, иконка в шести размерах, цвета, варианты фона |
| `sidebar-logo.png` | образец знака в сайдбаре интерфейса, увеличение ×3 |
| `brandboard.png` | тот же брендборд изображением — для презентаций и вставки в документы |

Для разработки и промо-материалов готовятся также `logo`, `logo-dark`, `logo-light`,
`icon`, `icon-dark`, `icon-light`, `favicon`, `app-icon`, `social`, `docs`
и `mark-only` в нужных размерах.

## 12. Что запрещено

- Растягивать и сжимать знак непропорционально.
- Перекрашивать знак вне фирменных градиентов.
- Менять местами цвета лент.
- Размещать знак на пёстром фоне без подложки.
- Использовать растровую версию знака там, где нужен вектор.
- Соседствовать с прежним названием KSTU Workspace в одном макете.
- Использовать эмодзи и сторонние иконки вместо знака.
