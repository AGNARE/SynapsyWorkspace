## О чём окно

Опасное действие: Git и Gantt не работают без подсистемы задач. Окно показывает, что именно отключится, и требует явного подтверждения.

## Из чего состоит

- Предупреждение со списком зависимых модулей и бейджами типов
- Пояснение: данные не удаляются, обратно модули сами не включатся
- Флажок «Я понимаю последствия отключения»
- Подвал с опасной кнопкой в отключённом состоянии

## Что решил и почему

- Список зависимых, а не общая фраза «зависят другие модули»
- Кнопка гаснет, пока флажок не отмечен: подтверждение должно быть действием
- Отдельно сказано, что обратно модули не включатся сами — это неочевидно

## Состояния и краевые случаи

- Нет зависимых модулей: обычное подтверждение без списка
- Отключение обязательного модуля: кнопка недоступна с пояснением
- Флажок отмечен: опасная кнопка становится активной
