## О чём окно

Задача удаляется вместе с историей, но вложения остаются в хранилище. Окно перечисляет последствия прямо, без общих слов.

## Из чего состоит

- Список последствий: связи в графе, ссылки в статьях, вложения
- Флажок «Удалить также вложения»
- Подвал: «Отмена» и красная кнопка «Удалить задачу»

## Что решил и почему

- Последствия перечислены: человек понимает, что именно теряет
- Вложения по умолчанию остаются — их удаление отдельное решение
- Красная кнопка без подтверждения: действие обратимо не полностью, но не катастрофично

## Состояния и краевые случаи

- Задача уже удалена: окно закрывается с сообщением
- Задача с вложениями: флажок доступен, снят по умолчанию
- Нет прав на удаление: кнопка недоступна с пояснением
