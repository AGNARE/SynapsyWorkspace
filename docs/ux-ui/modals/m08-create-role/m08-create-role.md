## О чём окно

Системные роли изменять нельзя, поэтому окно создаёт только новую. Матрица нужна не для красоты, а чтобы видеть пересечения прав.

## Из чего состоит

- «Название роли» и «Скопировать права у» — можно взять готовую роль за основу
- Поле описания
- Матрица прав: шесть ресурсов на четыре действия
- Подвал: «Отмена» и «Создать роль»

## Что решил и почему

- Матрица, а не чек-листы по ролям: сравнивать роли можно только рядом
- Копирование прав у существующей роли экономит время
- Шесть ресурсов — ровно те, что перечислены в требованиях

## Состояния и краевые случаи

- Название занято: красная рамка и пояснение
- Ничего не отмечено: роль без прав создать нельзя
- Системная роль: поля матрицы отключены с пояснением
