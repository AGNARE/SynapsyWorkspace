## О чём окно

Связи видны в графе и влияют на ответы ассистента. Окно даёт найти нужное и отметить несколько сущностей сразу.

## Из чего состоит

- Поле поиска и вкладки по типам: задачи, статьи, файлы
- Строка выбранного: чипы с крестиками
- Список результатов: отметка, бейдж типа, название и пояснение
- Подвал: «Отмена» и «Привязать (2)»

## Что решил и почему

- Число в кнопке показывает, сколько отмечено — не нужно считать глазами
- Бейдж типа рядом с названием: видно, что привязываешь
- Поиск вместо дерева: связи ищут по смыслу, а не по расположению

## Состояния и краевые случаи

- Ничего не найдено: подсказка сменить вкладку или уточнить запрос
- Ничего не отмечено: кнопка неактивна
- Много выбранного: строка чипов переносится на вторую строку
