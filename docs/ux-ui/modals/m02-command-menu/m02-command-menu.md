## О чём окно

Палитра открывается поверх экрана и даёт добраться до любого раздела или создать сущность, не трогая мышь. Заголовка нет — первая строка сразу поле поиска.

## Из чего состоит

- Поле поиска с подсказкой про Esc
- Три группы строк: «ПЕРЕЙТИ», «СОЗДАТЬ», «НЕДАВНЕЕ»
- Активная строка подсвечена, слева иконка, справа подсказка клавиши
- Внизу строка навигации: стрелки, Enter, Esc

## Что решил и почему

- Группы, а не один список: человек ищет либо раздел, либо действие, либо недавнее
- Подсказки клавиш прямо в строках — палитра учит себя использовать
- Недавнее внизу: до него доходят, когда не помнят точное название

## Состояния и краевые случаи

- Пустой ввод: показываем недавнее и частые команды
- Ничего не найдено: подсказка, что искать можно по названию раздела
- Долгий список: прокрутка внутри групп
