## 4. Что беру следующим

Что осталось, по приоритету:

1. Собрать компоненты в Figma — плагин готов, в папке `synapse-figma-plugin`
2. Перенести состояния и сводные листы в Figma

**Решено и не делаем:** набор иконок (остаются геометрические),
локализация (интерфейс только на русском), состав навигации (разобран),

**Сделано:** модальные окна — тринадцать, в папке [`synapse-figma-modals/`](../../synapse-figma-modals).
Состояния — двенадцать реальных экранов в папке [`synapse-figma-states/`](../../synapse-figma-states),
плюс раздел «Состояния и краевые случаи» в описании каждой страницы.

## 6. Правила ведения

- Один артефакт — одна строка со ссылкой на задачу.
- Ветка называется по задаче: `feat/ux-ui-*`, `docs/ux-ui-*`.
- Коммит содержит `Refs #N` или `Closes #N`.
