## Как читать описание экрана

Один экран — один файл. Внутри: сам макет, рассказ о том, зачем экран нужен,
из чего он собран, откуда решения, что не получилось и что делаю дальше.
В конце — короткий журнал по этому экрану.

## Как добавить экран

1. Взять номер и имя из Figma — следующий свободный `NN-имя`.
2. Скопировать структуру описания у соседнего экрана.
3. Положить рядом сам макет и превью.
4. В шапке указать ссылку на узел Figma.
5. Добавить строку в [TASKS.md](TASKS.md) со ссылкой на задачу.
