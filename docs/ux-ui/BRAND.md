# Бренд Synapse Workspace

## 1. Название и написание

Продукт — **Synapse Workspace**. В интерфейсе лого-лок разбит на две строки:
`SYNAPSE` (15/700 `#172033`) и `Workspace` (15/700 `#6366F1`).

Историческое имя **KSTU Workspace** выведено из употребления (коммит `56206ed`
«chore: rebrand KSTU Workspace as Synapse»). В старых макетах встречаются оба имени
одновременно — это дефект, а не вариант.

## 2. Знак

- Формат: вектор, один силуэт + наложенная нижняя лента.
- Градиент знака: `#713BFF → #4E69FF → #00D7E8`.
- Градиент ленты: `#00CFE8 → #356EFF → #7A35FF`.
- Файл: `logo-mark.svg`. В сайдбаре экранов знак стоит слева от лого-лока, размер 26×31,
  координаты `x=20, y=21`. Подписи `SYNAPSE` и `Workspace` — справа от знака, `x=58`.

## 3. Цвет

| Роль | Значение | Где применяется |
|---|---|---|
| Бренд-акцент | `#6366F1` | лого, иконки, выделение, декор. Белый текст на нём не ставим |
| Действие / ссылка | `#4F46E5` | кнопки, активный пункт, ID задачи. Белый текст допустим |
| Градиент бренда | `#8B5CF6 → #06B6D4` | декор, обложки, акцентные блоки |
| Тёмная подложка | `#050B1D → #111C3D` | обложки, hero-блоки, splash |

Полный набор интерфейсных токенов — в [RULES.md](RULES.md), раздел 4.

## 4. Типографика

Шрифт интерфейса — **Inter**. Начертания: 500 (тело), 600 (акцент), 700 (заголовки).
Минимальный кегль — 11 px. Полная шкала — в [RULES.md](RULES.md), раздел 6.

Ограничение: покрытие кыргызской кириллицы (ӊ, ө, ү) у Inter не подтверждено.
До проверки глифов киргизская локализация на этом шрифте не гарантируется.

## 5. Что запрещено

- Растровые логотипы и знаки (в старых файлах знак вставлен картинкой base64).
- Смешение брендов KSTU и Synapse в одном макете.
- Перекраска знака вне указанных градиентов.
- Эмодзи и юникод-глифы вместо иконок.
