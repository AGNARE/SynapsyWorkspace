# Что ещё не готово

Честный список того, что осталось по интерфейсу. Обновляется по ходу работы.

## 1. Модальные окна — готовы

Все тринадцать окон собраны в редактируемом SVG и лежат в папке
[`synapse-figma-modals/`](../../synapse-figma-modals) — оттуда их переносят в Figma.
Описания каждого окна — в [ОПИСАНИЯ.md](../../synapse-figma-modals/ОПИСАНИЯ.md).

**Что осталось по модалкам:** собрать из них компоненты с вариантами в Figma.

## 2. Состояния — готовы

Пять листов в папке [`synapse-figma-states/`](../../synapse-figma-states):

| Лист | Что показывает |
|---|---|
| s01 | пустые состояния: задачи, база знаний, файлы, участники, ассистент |
| s02 | загрузка: скелетоны метрик, таблицы, дерева, ответа ассистента |
| s03 | ошибки: загрузка, недоступный ассистент, нет прав, ошибка сохранения |
| s04 | пространство без модулей |
| s05 | доступность по ролям: владелец, редактор, читатель |

Раздел «Состояния и краевые случаи» добавлен в описание каждой из 17 страниц.

## 3. Пространство без модулей — решено и нарисовано

Решение: **пункт навигации не скрываем**, а показываем с серой пламкой «выкл.».
Иначе человек не поймёт, куда делся раздел, и будет искать его в настройках.

Зависимые модули (Граф от Wiki, Gantt от подсистемы задач) показаны без переключателя,
с пометкой «зависит». Лист — `s04` в наборе состояний.

## 4. Доступность по ролям — решено и нарисовано

Правило: роль не меняет внешний вид экрана, она меняет доступные действия.
Читатель видит ту же структуру, но без возможности что-то поменять.
Сравнение трёх ролей на одном экране — лист `s05`.

## 5. Иконки

В макетах стоят простые геометрические фигуры. Нужен набор под характер продукта:
строгий, но не безликий. После выбора — заменить во всех экранах и модалках.

## 6. Локализация

Интерфейс нарисован только на русском. По ТЗ нужен второй язык, плюс нужно проверить,
покрывает ли шрифт нужные глифы — от этого зависит выбор шрифта.

## 7. Компоненты в Figma

Из готовых макетов собрать автокомпоненты с вариантами: кнопки, поля, бейджи,
карточки, модальные окна. Сейчас всё нарисовано группами, повторяющимися вручную.

- расхождения с ТЗ по составу модулей
