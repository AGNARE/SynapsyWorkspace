# Что ещё не готово

Честный список того, что осталось по интерфейсу. Обновляется по ходу работы.

## 1. Модальные окна — нарисовано 4 из 13

Спецификация описывает тринадцать окон, в макетах нарисовано четыре.

**Нарисованы:** создание задачи, командное меню, приглашение участников,
каскадное отключение модуля.

**Осталось нарисовать:**

| Окно | Размер | Особенность |
|---|---|---|
| Архивирование пространства | 720 | объясняет последствия, обратимое действие |
| Удаление безвозвратно | 560 | опасное действие, нужно подтверждение |
| Загрузка файлов | 720 | прогресс по каждому файлу, ошибки |
| Создание роли | 880 | матрица прав, самая широкая форма |
| Привязка знаний | 720 | поиск и выбор сущностей |
| Удаление задачи | 480 | опасное действие |
| Восстановление версии файла | 560 | подтверждение отката |
| Секрет webhook для Git | 560 | скрытое значение, копирование |
| Лист состояний модальных окон | 1440×1024 | сводная страница: норма, ошибка, загрузка |

## 2. Состояния — почти не отрисованы

Это самое заметное, чего не хватает: макеты показывают только «всё хорошо».

- пустое состояние: нет задач, нет материалов, нет команды
- загрузка: скелетоны для метрик и списков
- ошибка загрузки: сообщение и кнопка «Повторить»
- ассистент недоступен: что показывать вместо поля ввода
- ошибки валидации в формах: пустое обязательное поле, занятое название
- состояние отправки на кнопках
- длинные значения: названия задач, имена участников, адреса

## 3. Пространство без модулей

Экран не отрисован. По ТЗ модули можно отключать, значит навигация и экраны должны
это учитывать, а не показывать пункты, за которыми ничего нет.

Что нужно решить: скрывать пункт совсем или показывать с пометкой «модуль отключён»,
и что видно на месте самого экрана.

## 4. Доступность по ролям

Роли видят разное: владелец, редактор, читатель. Состояния интерфейса под каждую роль
не отрисованы — непонятно, что видит читатель на экране задач, в настройках
и в разделе участников, и какие действия у него скрыты.

## 5. Иконки

В макетах стоят простые геометрические фигуры. Нужен набор под характер продукта:
строгий, но не безликий.

## 6. Локализация

Интерфейс нарисован только на русском. По ТЗ нужен второй язык, плюс нужно проверить,
покрывает ли шрифт нужные глифы — от этого зависит выбор шрифта.

## 7. Прочее

- навигация: в части макетов есть пункты, которых нет в ТЗ — нужно свести состав
- расхождения с ТЗ по составу модулей
- адаптив не требуется: концепция десктопная, 1440×1024
