# Synapse Workspace — документация интерфейса

Репозиторий с документацией UX/UI проекта Synapse Workspace: описания экранов,
дизайн-система, бренд, аудит и карта работ.

## Раскладка

```
docs/ux-ui/
├── README.md          — о каталоге, как читать, команда
├── WORKLOG.md         — журнал работы по этапам
├── BACKLOG.md         — что ещё не готово
├── RULES.md           — дизайн-система
├── BRAND.md           — бренд
├── AUDIT.md           — аудит интерфейса
├── TASKS.md           — карта работ
├── ISSUE-COMMENTS.md  — готовые комментарии к задачам проекта
├── NEW-ISSUES.md      — каких задач не хватает на доске
├── pages/01-overview … pages/17-archive   — описание + макет + превью
└── modals/m01-create-task                 — описание + макет
```

Каждый экран — отдельная папка: внутри описание со ссылкой на Figma,
сам макет в SVG и картинка для быстрого просмотра.

## С чего начать

1. [WORKLOG.md](docs/ux-ui/WORKLOG.md) — что сделано по этапам и что дальше.
2. [pages/01-overview/01-overview.md](docs/ux-ui/pages/01-overview/01-overview.md) — пример описания экрана.
3. [BACKLOG.md](docs/ux-ui/BACKLOG.md) — что ещё не готово.

## Статус

Описаны все **17 экранов** и одно модальное окно. Макеты — в редактируемом SVG,
живым текстом, без растров.

Дальше по плану: 9 оставшихся модальных окон, состояния экранов
(пустое, загрузка, ошибка), режим «пространство без модулей», доступность по ролям.
