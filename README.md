# Synapse Workspace — три варианта документации UX/UI

Репозиторий для выбора раскладки каталога документации интерфейса.
**Содержимое одинаковое во всех трёх вариантах** — отличается только структура каталогов.
Внутри уже лежат живые примеры: экран **01-overview** и модальное окно **m01-create-task**.

## Три варианта

| Вариант | Раскладка | Путь | Описание страницы лежит в |
|---|---|---|---|
| **A** | папка на страницу | `variant-A/docs/ux-ui/` | `pages/01-overview/01-overview.md` |
| **B** | плоско + общий `img/` | `variant-B/docs/ux-ui/` | `pages/01-overview.md` |
| **C** | как у команды, рядом с `use_case` | `variant-C/docs/human_docs/ux-ui/` | `01-overview.md` |

Смотри в каждом варианте по одному и тому же маршруту:
`README.md` → `RULES.md` → `pages/…` (или `01-overview.md`) → `modals/…`.

## Что одинаково во всех трёх

| Файл | Назначение |
|---|---|
| `README.md` | навигация, как добавить страницу, раздел «Команда» |
| `RULES.md` | дизайн-контракт: сетка 4 px, токены, типографика, компоненты, статусы, язык, доступность, чек-лист |
| `BRAND.md` | брендборд: знак, градиенты, цветовые роли, шрифт, запреты |
| `AUDIT.md` | аудит интерфейса: источники, находки по макетам, факты по репозиторию |
| `TASKS.md` | карта работ: issue → исполнитель → артефакт → статус |
| описание страницы | 8 разделов, включая UX/UI-подход и сверку с кодом |
| описание модалки | те же 8 разделов для окна `lg` 720 |
| `.svg` + `.png` | сам экран и превью (XML проверен) |

## В чём разница

**A — папка на страницу.** Описание, вектор и превью всегда рядом.
Плюс: у страницы есть своё место под дополнительные файлы.
Минус: три уровня вложенности, двадцать папок, имя файла дублирует имя папки.

**B — плоско + общий `img/`.** Все описания одним уровнем, изображения отдельно.
Плюс: короткое дерево, описание открывается как единый документ с картинкой прямо на GitHub.
Минус: описание и картинка разъехались, пути `../img/` в каждом файле.

**C — как у команды.** Файлы лежат плоско рядом, как `use_case.md` + `use_case.png`.
Плюс: полное единообразие с существующим `docs/human_docs/`.
Минус: 60 файлов в одном каталоге, страницы и модалки в одной куче.

## Статус

Это **тестовый прогон раскладки**, а не итоговая поставка. Описаны один экран и одна модалка.
После выбора варианта по этой же схеме собираются остальные страницы.

Фактические данные в документах взяты из проверенных источников:
Figma-файл Synapse Workspace, ТЗ, приватный репозиторий `Software-Engineering-KSTU/synapse`
(ветки, коммиты, issues #1–#9) и локальный набор из 17 экранов.
