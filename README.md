# Synapse Workspace — документация интерфейса

Репозиторий для просмотра и разбора документации UX/UI проекта Synapse Workspace.

## Раскладка

```
docs/ux-ui/
├── README.md      — о каталоге, как читать, команда
├── WORKLOG.md     — журнал работы по датам
├── RULES.md       — дизайн-система
├── BRAND.md       — бренд
├── AUDIT.md       — аудит интерфейса
├── TASKS.md       — карта работ
├── pages/01-overview/     — описание экрана + макет + превью
└── modals/m01-create-task/ — описание окна + макет
```

Каждый экран — отдельная папка: внутри описание, сам макет и картинка для быстрого просмотра.

## С чего начать

1. [WORKLOG.md](docs/ux-ui/WORKLOG.md) — что делалось с 5 октября и что дальше.
2. [pages/01-overview/01-overview.md](docs/ux-ui/pages/01-overview/01-overview.md) — пример описания экрана.
3. [modals/m01-create-task/m01-create-task.md](docs/ux-ui/modals/m01-create-task/m01-create-task.md) — пример описания окна.

## Соседние варианты раскладки

В `variant-B/` и `variant-C/` лежат два альтернативных способа разложить те же файлы.
Они оставлены для сравнения — рабочей выбрана раскладка из корня (`docs/ux-ui/`).
