## 1. Назначение и роль в сценарии

Стартовый экран после входа в рабочее пространство. Отвечает на вопрос
«что от меня ждут сегодня» и служит точкой входа в задачи, знания и AI-ассистента.

Экран закрывает три модуля из ТЗ: управление задачами (сводка и «Моя работа»),
база знаний (блок «Знания»), AI-ассистент (блок запроса к пространству).

## 4. UX/UI-подход и обоснование

- **Иерархия по срочности, а не по модулям.** Первым идёт «Моя работа», а не список
  проектов: пользователь приходит за своим, а не за обзором всего пространства.
- **Главное действие — верхний правый угол.** Кнопка «Создать» стоит на `y 88..124`,
  то есть на линии заголовка, а не в потоке контента. Это F-паттерн: взгляд
  заканчивает первую строку справа.
- **KPI — это сигнал, а не метрика.** Каждое число сопровождается пилюлей-подсказкой
  («требует внимания», «срок до 23:59», «есть зависимости», «ожидают решения»),
  поэтому рост числа читается как задача, а не как статистика.
- **Закон Хика.** Четыре карточки в KPI-строке — предел, за которым выбор перестаёт
  быть быстрым. Пятая метрика должна уходить в отдельный экран.
- **Прогрессивное раскрытие.** Экран показывает состояние, но не детали: описание,
  история и связи задачи живут на `04-task-detail`, а не здесь.
- **Разделение «что делаю» и «что происходит».** Слева — мои задачи, справа — активность
  команды. Два разных вопроса, поэтому две колонки, а не один список.
- **AI — равноправный блок, а не виджет в углу.** Ассистент занимает четверть экрана:
  по ТЗ это не справочная, а рабочий инструмент.
- **Статус не кодируется только цветом** — рядом всегда текст («На проверке», «В работе»).
- **Тактильная плотность.** Основной текст 13 px, мета 12 и 11 px: на 1440 px помещается
  сводка на день без скролла и без мелкого шрифта ниже 11 px.

## 5. Соответствие правилам

- [x] Холст 1440×1024, есть `viewBox`, `<title>`, `<desc>`
- [x] Группы `sidebar`, `topbar`, `content` в правильном порядке
- [x] Нет `<style>`, `<image>`, `transform`, `filter`, `mask`, классов, эмодзи
- [x] Весь текст — `<text>` с координатами, шрифт Inter
- [x] Цвета только из палитры, кегль не меньше 11 px
- [x] Английские подписи только из разрешённого списка (Git, Gantt, Kanban, AI, Wiki, Ctrl K)
- [x] Размер файла 19,9 КБ — в пределах 30 КБ
- [x] Автопроверка XML пройдена
- [ ] Иконки — геометрические заглушки 16×16, заменить на иконную систему
- [ ] Состояния наведения, фокуса и загрузки не нарисованы

## 8. Открытые вопросы

1. Пятая метрика в KPI — нужна ли, и какая? Сейчас лимит четыре по закону Хика.
2. Блок «Знания» дублирует навигацию в Wiki. Оставить как быстрый доступ или убрать?
3. Нужен ли блок активности при пустом пространстве (нет команды, нет событий)?
4. Приветствие «Добрый день, Арген» — обращение по имени берём из профиля или из сессии?
