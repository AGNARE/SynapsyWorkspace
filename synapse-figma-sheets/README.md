# Сводные листы Synapse Workspace — набор для Figma

Два листа, которые собирают продукт целиком: дизайн-система и карта потоков.
Служебные — их не показывают пользователю, они нужны команде и для защиты проекта.

## Что в папке

| Файл | Что внутри |
|---|---|
| `18 — Дизайн-система.svg` | цветовые токены, типографика, компоненты, сетка и правила |
| `19 — Карта потоков.svg` | путь от входа до знаний, развилки по состояниям, ролям и модулям |
| [_preview/](_preview) | PNG-превью обоих листов |
| [ОПИСАНИЯ.md](ОПИСАНИЯ.md) | что показывает каждый лист |
| [../docs/ux-ui/README.md](../docs/ux-ui/README.md) | что внутри и журнал работы |

## Как перенести в Figma

Установи **Inter** и перетащи `.svg` на холст — каждый займёт кадр 1440×1024.

## Про третий лист

В старой сборке был ещё `20-ux-qa-states` — служебный лист состояний.
Он **не нужен**: набор [`synapse-figma-states/`](../synapse-figma-states) делает то же
самое, но подробнее — двенадцать реальных экранов вместо сводки миниатюр.

## Один момент про иконки

В компонентах и на карте потоков стоят простые геометрические фигуры, как и во всех
остальных макетах. Отдельный набор иконок не рисуем — решено оставить текущий стиль.
