## Как перенести в Figma

1. Установи шрифт **Inter** — иначе текст подменится и метрики поедут.
2. Открой нужную страницу файла Synapse Workspace.
3. Перетащи файлы `.svg` прямо на холст. Можно все сразу — каждый займёт кадр 1440×1024.
4. Слои придут с именами: `backdrop`, `dialog`, `dialog-surface`, `btn-cancel` и так далее.
5. Подложку можно удалить: в Figma окно кладут поверх готового экрана, а `backdrop` нужен только чтобы видеть затемнение в превью.

## Что внутри каждого файла

- Живой текст (`<text>`), а не кривые: подписи правятся прямо в Figma.
- Только вектор: ни растров, ни внешних ссылок, ни CSS-классов.
- Никаких `transform`: все координаты абсолютные, поэтому импорт не съезжает.
- Цвета — из утверждённого набора токенов (`RULES.md`, раздел 4).
- Опасные действия — красным `#B91C1C`, отключённые кнопки — `#F1F5F9` с серой подписью.

## Что стоит поправить при доработке

1. **Иконки.** Внутри простые геометрические фигуры. Заменить на иконную систему.
2. **Состояния.** Показано основное состояние; наведение, фокус и загрузка — на листе `m13`.
3. **Компоненты.** Кнопки и поля внутри окна повторяются как группы. В Figma из них
   нужно собрать автокомпоненты с вариантами.
